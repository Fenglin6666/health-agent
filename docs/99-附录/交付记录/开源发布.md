### 2.2 云隧道地址

`web/functions/index.ts` 第 7 行原本硬编码：

```ts
const BACKEND_BASE = 'https://nicole-contracts-html-invisible.trycloudflare.com'
```

这是 cloudflared 临时隧道，直指本机 8080 后端。**隧道地址本身就是入口**，写进公开仓库等于把本机服务（含会话与健康档案）挂到公网。

改为环境变量注入，并在缺失时显式返回 503：

```ts
const BACKEND_BASE = Deno.env.get('BACKEND_BASE') ?? ''
if (!BACKEND_BASE) return json(503, { error: 'backend_not_configured' })
```

### `.gitattributes`

```gitattributes
* text=auto eol=lf
*.bat text eol=crlf
```

`*.bat` 强制 CRLF 是踩过坑的：之前 `start.bat` 用 LF 换行，cmd 解析 `goto` 标签直接失败。不锁换行符，clone 到 Linux 再传回来就会坏。

## 5. 遗留风险

### 5.1 cloudflared 隧道仍在运行

发布时检查到：

```
cloudflared.exe    PID 19712
TCP 0.0.0.0:8080   LISTENING   25712
```

两件事需要注意：

1. **隧道进程没关**。地址虽已从代码移除，但如果这条隧道还活着，且该地址此前曾出现在已发布的页面或分享链接里，入口依然有效。建议确认用途后关掉：`taskkill /PID 19712 /F`。
2. **8080 监听在 `0.0.0.0` 而非 `127.0.0.1`**。同一局域网内任何设备都能直接访问后端，不需要经过前端。本地开发建议绑回环地址。

### 5.2 语料授权

5000 条语料是公开渠道的用户提问聚合，**未逐条回溯出处并取得授权**。已在 README 写明仅作技术评测用途。若要商用，需自行确认。

### 5.3 提交历史不可改

首次提交即包含全部文件。若之后发现还有敏感内容，`git rm` 只能删掉最新版本，历史里仍在。届时需要 `git filter-repo` 重写历史并强推——比现在多花十倍力气。**所以发布前这一轮全量扫描不能省。**
