### 关于门禁 5 无数据

降级率要统计"模型调用失败后走了兜底文案"的比例，但当时没有埋点。属于观测缺口，不是通过。

## 5. 恢复后按这个顺序重跑

```bash
# 1. L1 四域基线（最慢，先起）
curl -X POST "localhost:8080/api/v1/evaluation/l1?domain=all"

# 2. 门禁 2 主路由
curl -X POST "localhost:8080/api/v1/evaluation/route?trials=3"

# 3. 门禁 1 红旗
curl -X POST "localhost:8080/api/v1/evaluation/redflag"

# 4. 门禁 3 多意图
curl -X POST "localhost:8080/api/v1/evaluation/sample"
```

跑完把新结果放进 `05-测试执行/结果/`，更新本文件的第 1、3 节，再动 `README.md` 的状态描述。

**顺序不能反**：L1 最慢且依赖最全，先跑它能把环境问题暴露出来；红旗是纯规则秒级，放最后不影响。
