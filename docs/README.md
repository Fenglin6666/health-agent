## 9. 怎么用这份索引

- **要改代码** → 从 `02-方案/详细设计/` 找对应册，第 3 节是签名，第 5 节是边界。
- **要判断能不能发** → 只看 §5 里标"可作基线"的两份；其余一律不算证据。
- **要查某个 bug 是谁的责任** → 先看 `缺陷与验收/defects` 的六分类，再顺着分类去对应的 CR 或 issue。
- **要新增需求** → 照 `增量-*` 的模式开新文档，不要直接改 `主需求-需求规格.md`。
- **要知道走到哪一步了** → 看 `00-流程/门禁记录.md` 第 1 节。
