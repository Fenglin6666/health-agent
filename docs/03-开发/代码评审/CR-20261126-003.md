## 5. 与设计的偏差

| 偏差 | 原因 |
|---|---|
| `api/client.ts` 未拆成 client/sessions/feedback 三个文件 | 会话相关函数与类型被 4 个模块引用，拆开后 import 变多；283 行仍在可维护范围。若继续增长再拆 |
| 消息删除未实现 | 规格里明确不做：需要消息主键与级联，收益低于成本；举报已覆盖合规诉求 |
| 分享未做"复制链接" | 没有服务端渲染页，链接分享会暴露会话 id，先只做图片 |

## 6. 风险

| 风险 | 影响 | 处置 |
|---|---|---|
| 移动端长按与文本选择冲突 | 长按可能选中文字而不是弹菜单 | 菜单仍可通过右键/桌面端使用；后续加 `touch-action` 与选择态判断 |
| 反馈依赖 `done.turn` | 若 done 丢失，按钮不显示（`canFeedback` 为 false） | 降级为不显示，不会提交错轮次 |
| localStorage 被禁用 | 刷新后新建会话 | 已 try/catch 降级 |
| 分享图字体 | 无系统中文字体时可能显示方框 | canvas 用系统字体栈，主流环境都有 |
| 老客户端不认 `clarify` | 忽略事件，正文照常 | 协议向后兼容，已确认 |
