## 5. 更正：模型可以读图（原结论有误）

**上一版写的"deepseek-chat 不支持视觉、图片消息只会回'看不清'"是错误结论，已撤回。**

错误来源：当时用一张 **1×1 透明 PNG** 测试，模型回复"看不清"。
我把"图里没有内容"误判成了"模型没有视觉能力"。

用一张 640×240、带文字的生化报告图复测：

```
输入：这张报告有什么问题 + 报告图片
路由：manager → report
回答：甘油三酯 7.8 mmol/L（参考 0.4–1.7），是参考上限的 4 倍多，属于重度升高……
      总胆固醇 6.2 mmol/L，同样偏高
```

数值、单位、参考范围全部读对，并给出了急性胰腺炎风险的判断。

**结论**：粘贴图片功能没有模型层限制。1×1 空图返回"看不清"是正确行为。

教训：验证模型能力时，测试样本必须包含可识别的信息；
用空白图得到的否定结论不成立。

## 6. 风险

| 风险 | 处置 |
|---|---|
| 全局 paste 抢走其他输入框的粘贴 | 只有剪贴板含 `image/*` 才 `preventDefault`；纯文本完全放行（已实测） |
| 富文本 + 图片混合粘贴把 HTML 塞进输入框 | 有图即 `preventDefault`，只取图片 |
| 多图覆盖 | 取第一张 + 提示，与"重新选文件"行为一致 |
| 粘贴超大截图卡顿 | 复用 `compressImage`，长边压到 1600；压缩在 canvas 完成，不阻塞输入 |
| EXIF 泄露位置信息 | canvas 重编码为 JPEG，元数据天然剥离 |
